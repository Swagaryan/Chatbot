# Telegram AI ChatBot (Pyrogram Based)

यह एक स्मार्ट Telegram चैटबॉट है जो यूज़र को auto-reply देता है, जिसमें शामिल हैं:
- दर्द भरी शायरियाँ
- फिल्मी डायलॉग
- आम बातचीत के जवाब
- भविष्य में sticker reply का फीचर

## ✨ फीचर्स:

- ✅ 50+ हिंदी शायरियाँ (shayari_data.py में)
- ✅ Dialogues और Creative Replies
- ✅ AI-Style जवाब
- ✅ Lightweight Pyrogram Code
- ✅ Fast Deployment on Render.com
